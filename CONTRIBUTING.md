# Contributing to DecodeLabs AI Assistant

We welcome contributions to improve this project! Please review the guidelines below to submit improvements or report issues.

## Code Standards
- Ensure all codes follow **PEP8** styles.
- Include complete **docstrings** and **type annotations** for any new modules or functions.
- Run the full automated testing suite before making any submission:
  ```bash
  python -m unittest tests/test_chatbot.py
  ```

## How to Submit a Pull Request
1. Fork the repository and create your feature branch from main.
2. Commit your changes with detailed explanations.
3. Push to your branch and open a Pull Request.
4. Ensure all unit tests pass on target environments.
