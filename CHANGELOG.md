# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-15

### Added
- **ASCII Art Banner**: Startup DecodeLabs logo printed once upon initialization.
- **Unicode Border Enclosures**: Beautiful message box frames with prefix alignment.
- **Smart Synonym Recognition**: Maps synonyms like 'greetings' or 'howdy' to central intent triggers.
- **Dynamic System Actions**: Native date/time checking and clear terminal commands.
- **Lightweight Memory Store**: Tracks user name declarations and messages counts.
- **Performance Diagnostics**: Diagnostic details toggled using 'debug on' and 'debug off' showing confidence, tiers, and times.
- **Automated Logging**: Output transactions trails saved in `logs/chatbot.log`.
- **Unit Testing Suite**: 15 complete automated tests in `tests/test_chatbot.py`.
